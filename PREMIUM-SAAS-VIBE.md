**Effect:** Cards lift and scale elegantly on hover

### 2️⃣ Smooth Page Transitions
**What's added:**
```javascript
const pageTransition = {
  initial: { opacity: 0, y: 20 },
  animate: { opacity: 1, y: 0 },
  exit: { opacity: 0, y: -20 },
  transition: { duration: 0.3 }
};

<motion.div {...pageTransition}>
```

**Applied to:**
- Home page
- Cart page
- Checkout page

**Effect:** Pages fade + slide when navigating  
**Vibe:** Premium navigation feel ✅

---

### 3️⃣ Gradient Header
**What's added:**

**Effect:** Navbar has subtle blue-to-indigo gradient  
**Vibe:** Modern SaaS instantly ✅
